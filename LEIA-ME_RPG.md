# Cross Adventures

Projeto real: C:\Users\finan\OneDrive\Documentos\cross-adventures.

Abra project.godot no Godot 4.7.1 e pressione F5. Escolha INICIAR AVENTURA. F1 abre o guia e pausa a partida; F1/Esc fecha. Esc abre a pausa.

Player1: WASD, F para atacar/combo, G para escudo frontal, KP 0 para saltar e KP 5 para interagir/empurrar.
Player2: setas, mouse para mirar, clique esquerdo para tiro/carga, clique direito para dash, Espaço para saltar e E para interagir. C alterna elementos nas fases 3/4. Tab trava a mira e mostra os próximos ricochetes. V alterna a visão geral do mapa. M alterna os efeitos e R reinicia a sala.

Quatro fases: Jardim da Provação, Galeria dos Ecos, Oficina das Quatro Fontes e Santuário do Guardião.

Guia dos puzzles: documentacao/FASES.md. Direção de arte: documentacao/DIRECAO_VISUAL.md. Contexto de continuidade: documentacao/CONTEXTO_DO_JOGO.md. Os inventários de assets são históricos. Recursos sem uso foram arquivados fora do jogo; consulte documentacao/LIMPEZA_ASSETS.md para o estado atual e recuperação local.

Mapas reconstruídos com o pacote oficial gratuito CraftPix: salas conectadas, canais animados, paredes de pedra e iluminação localizada. Origem e licença em assets/mapa/CRAFTPIX_DUNGEON/FONTE.md.

HUD e menus agora compartilham fonte pixel, quadros, efeitos de entrada e sons. Referência: documentacao/INTERFACE_PIXEL.md.

Para evitar a cópia antiga MeuJogo, use os atalhos “Jogar - Cross Adventures.lnk” ou “Abrir no Godot.lnk” nesta pasta. Veja documentacao/ABRIR_PROJETO_ATUAL.md.
